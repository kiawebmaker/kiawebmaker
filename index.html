FAQ Seputar Layanan

Jawaban ringkas atas pertanyaan yang sering diajukan calon klien kami.

Berapa lama waktu pengerjaan website/aplikasi..?

Landing page sederhana membutuhkan waktu 3-5 hari. E-commerce atau Web App berkisar 2-3 minggu, sedangkan Aplikasi Mobile kustom membutuhkan waktu 3-6 minggu.

Komputer Jadul P4 atau Dualcore dng Windows XP / Windows 7 32bit bisakah dipakai..?

Bisa..!..Komputer lama P4 / Dualcore Windows XP atau Windows 7 32bit bisa dipakai, jika aplikasi atau GUI Offline akan kami buatkan versi 32bit dan jika Online menggunakan Pemrograman dan Framework versi modern bisa diakses lewat Browser anda.

Saya ingin membuat Website CMS dengan menggunakan Worpress bisakah..?

Bisa..!..Kami juga bisa menggunkan Worpress untuk CMS anda.

Apakah saya memperoleh source code penuh..?

Ya! Setelah pengerjaan selesai dan dilunasi, 100% hak milik source code beserta dokumentasinya diserahkan kepada Anda tanpa biaya tersembunyi.

Bagaimana jika terjadi kendala/bug setelah rilis..?

Kami memberikan garansi perbaikan bug gratis selama 1 hingga 3 bulan penuh setelah aplikasi dipublikasikan untuk menjamin kelancaran operational.
